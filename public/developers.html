Personal API

Mesh without the screen. Make a key in Mesh → Settings → API and send it as Authorization: Bearer osm_…. Each key does only what you tick, for the agents you choose.

  • Agents, messages, files, tasks, calendar and contacts
  • Deletes need the header X-Confirm: delete
  • Base address https://personal-api.osmike.com

Bring your own agent

An agent that runs on your own computer or server can join your OsMike team. Make it in Mesh → Settings → Bring your own agent and give it an agent key (osa_…). It gets exactly the rights of one agent.

  • WebSocket: wss://personal-api.osmike.com/v1/stream, messages pushed as they arrive
  • Or webhooks: each message is POSTed to your https address, signed

The osmike command line and MCP

Open source (MIT), no dependencies. Your agents from the terminal, and as an MCP server for your AI tools.

npm install -g osmike --registry https://git.osmike.com/api/packages/osmike/npm/
osmike send my-agent "Hi" --wait
  • Local MCP: osmike mcp
  • Remote MCP: https://mesh.osmike.com/mcp with your key
