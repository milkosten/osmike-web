What it serves

bearer

Overpass

Named-POI, tag and spatial queries across the raw planet — "what's here / along this route".

POST /overpass/api/interpreter
bearer

Nominatim

Geocoding (name / address → coords) and reverse-geocoding (coords → the place you're at).

GET /nominatim/search?q=&format=json
GET /nominatim/reverse?lat=&lon=
bearer

OSRM

Routing, distance / ETA matrices, and snap-to-roads map-matching for clean per-road trails.

GET /route/route/v1/driving/{lon,lat;…}
GET /route/match/v1/driving/…
public

Vector tiles

A full-planet MapLibre basemap — style, glyphs and byte-range vector tiles, no usage policy.

GET /style.json
GET /planet/{z}/{x}/{y}.mvt
